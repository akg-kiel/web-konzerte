## Linear Workflow

Linear is the single source of truth for task management.

### Ticket Process

1. **Start**: Read ticket -> Move to `In Progress`.
2. **Branch**: `feature/linear_ticket_id-short_description` (e.g., `feature/AKG-5-init`).
3. **Commit**: `AKG-XXX: message`.
4. **PR**: Create GitHub PR -> Move Linear to `In Review`.
5. **Done**: Move to `Done` ONLY after PR is merged.

**Note**: Link PRs to Linear tickets in the description.
