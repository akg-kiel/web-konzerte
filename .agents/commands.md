## Quick Reference Commands

| Task       | Command                             |
| :--------- | :---------------------------------- |
| Dev Server | `bun run dev`                       |
| Build      | `bun run build`                     |
| Linting    | `bun run lint`                      |
| Add UI     | `npx shadcn@latest add [component]` |
| Install    | `bun install`                       |
