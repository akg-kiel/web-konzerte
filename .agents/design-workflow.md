## Design Workflows

### frontend-design Skill

**IMPORTANT**: Always use the `frontend-design` skill for:

- Creating/Refactoring UI components.
- Responsive layouts & mobile-first design.
- Accessibility (ARIA) improvements.

### Process

1. **Plan**: Use `frontend-design` to propose the UI.
2. **Approve**: Wait for user review of the design.
3. **Implement**: Convert design to Astro/React/Tailwind code.
